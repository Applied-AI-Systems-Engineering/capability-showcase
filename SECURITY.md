# Security reporting

Report suspected vulnerabilities through [private vulnerability reporting](https://github.com/Khemology/capability-showcase/security/advisories/new). Include the affected commit, synthetic reproduction steps, expected behavior and impact. Do not post exploit details, credentials or personal data in public issues.

This repository contains disconnected synthetic demonstrations. Disabled integration templates are not production services. Do not attach live credentials or import these examples into a production instance without separate review and integrated testing.

Reports are reviewed within the demonstrated scope. No response-time guarantee or production security certification is claimed.
